Morse Code IoT Pager — EE250 Final Project
Abhigya Goel

OVERVIEW
--------
A Morse code pager across four physical nodes. Arduino Node A lets a user
tap Morse code using a touch sensor. The Raspberry Pi decodes the tap stream
in real time using a trained ML model and relays decoded messages to Arduino
Node B, which displays them on an LCD and blinks LEDs. A laptop runs a Flask
dashboard that visualizes the decoding process live.

NODES
-----
Node A: Arduino Uno R3 — capacitive touch sensor + buzzer (sender)
Node B: Arduino Uno R3 — 16x2 LCD shield + RGB LED + 2 LEDs (receiver)
Node C: Raspberry Pi — MQTT broker, serial bridge, ML decoder
Node D: Laptop — Flask-SocketIO dashboard

SETUP
-----
1. Training (run on laptop):
   cd training
   pip install numpy pandas scikit-learn joblib
   python generate_data.py
   python train_model.py

2. Pi setup:
   sudo apt install mosquitto mosquitto-clients
   pip install paho-mqtt pyserial joblib scikit-learn numpy
   # Copy pi/ folder to the Raspberry Pi
   # Start broker: sudo systemctl start mosquitto
   # Start bridge: python serial_bridge.py --port-a /dev/ttyUSB0 --port-b /dev/ttyUSB1
   # Start decoder: python ml_decoder.py

3. Dashboard (run on laptop):
   cd dashboard
   pip install flask flask-socketio paho-mqtt
   python app.py --broker pi.local

4. Arduino:
   Upload arduino/node_a/node_a.ino to first Arduino (sender)
   Upload arduino/node_b/node_b.ino to second Arduino (receiver)
   Connect both to Pi via USB

WIRING
------
Node A (no shield, all pins free):
  Touch sensor SIG  -> D2
  Buzzer positive    -> D3
  Buzzer negative    -> GND

Node B (LCD shield stacked, uses D4-D10 and A0):
  RGB LED R leg      -> D11 (220 ohm resistor)
  RGB LED G leg      -> D12 (220 ohm resistor)
  RGB LED B leg      -> D13 (220 ohm resistor)
  RGB LED cathode    -> GND
  Extra LED 1        -> D2  (1.5k ohm resistor)
  Extra LED 2        -> D3  (1.5k ohm resistor)

SERIAL PROTOCOL
---------------
Node A -> Pi (plain text):
  TAP,<duration_us>
  GAP,<duration_us>

Pi -> Node B (plain text):
  CHAR,<character>
  RGB,<r>,<g>,<b>
  MSG,<message_text>

MQTT TOPICS
-----------
pager/morse/raw/<node_id>             — raw tap/gap events (JSON)
pager/morse/raw/<node_id>/classified  — events with ML classification
pager/morse/decoded/<node_id>         — decoded characters + confidence
pager/status/<node_id>                — node online/offline state
pager/alert/<node_id>                 — RGB LED commands for Node B

ML APPROACH
-----------
Random Forest classifier trained on synthetic data. Features per event:
- Raw duration (ms)
- Duration / running session mean (speed normalization)
- Duration / previous duration (relative ratio)
- Is-tap flag (1 for tap, 0 for gap)

Classes: dot, dash, intra-letter gap, inter-letter gap, word gap

Training data: ~55k synthetic samples from realistic Morse sessions across
10/15/20/25 WPM speeds. Generated by simulating actual word sequences with
Gaussian noise, processed in natural sequential order to match inference.
